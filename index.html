يعتمد مباشرة على الجدول المنشور في Firebase. يرسل تذكيراً قبل 24 ساعة ثم قبل 15 دقيقة عبر WhatsApp Business Cloud API حتى لو كانت صفحات النظام مغلقة.
التذكيرات غير مهيأة بعد.
ملاحظة: مفتاح WhatsApp السري لا يُحفظ داخل هذا الملف. الإرسال التلقائي يتم من Firebase Cloud Function مستقلة وآمنة.
